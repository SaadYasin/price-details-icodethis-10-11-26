# Pricing Details Landing Page

A static landing page showcasing a business pricing/value proposition for a software product. The design uses a dark purple background, layered decorative circles, and two pricing/information cards to present the offer clearly and modernly.

## Preview

Open `index.html` directly in a browser, or serve the project locally for a smoother preview.

## Project Structure

- `index.html` — page structure, content, styling, and Tailwind setup
- `circle-blue.svg` — decorative blue circular asset used in the background

## Technologies Used

- HTML5
- Tailwind CSS via CDN
- Font Awesome for icons
- Plain static assets; no framework or build step required

## How to Run Locally

Option 1: Open directly

- Double-click `index.html` in the project folder, or
- Right-click the file and choose "Open with browser"

## Design Highlights

- Dark, premium background with layered gradient-like circular shapes
- Centered hero messaging focused on business package selection
- Two-column card layout for pricing criteria and service features
- Compact CTA button styled for conversion
- Responsive design that adapts across screen sizes
